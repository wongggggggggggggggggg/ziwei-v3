## 2. ¥1 可以玩幾多次？（推算，附公式）

**假設**（單次解讀）：
- 輸入 ≈ 900 tokens（system + 七段指令 + 三張牌名）
- 輸出 ≈ 1,200 tokens（7 段 × 120–200 字 + 標題）

```
高峰成本 = 900 × 0.30/1e6 + 1200 × 1.20/1e6
         = 0.00027 + 0.00144 = $0.00171
        ≈ ¥0.0121（用 7.1 匯率）
離峰成本 = 一半 ≈ ¥0.0061
```

| 情況 | 每篇成本（估算） | ¥1 可玩 |
|------|------------------|---------|
| deepseek-flash · 高峰 | ≈ ¥0.012 | **≈ 82 次** |
| deepseek-flash · 離峰 | ≈ ¥0.006 | **≈ 164 次** |
| deepseek-flash · 開 thinking | ≈ ¥0.016–0.026 | ≈ 38–62 次 |
| deepseek-v4-pro · 高峰 | ≈ ¥0.042 | ≈ 24 次 |

⚠️ 全部係**推算**：匯率會浮動、實際 token 數取決於 AI 回覆長度、cache hit 會令輸入便宜 50 倍。要精準，睇 <https://platform.deepseek.com/usage> 的實際用量。

**結論**：¥1 其實夠玩 **80 次左右**（唔開 thinking、避開高峰）。所以「每日 40 次上限」已經比 ¥1 更寬鬆，安全。

## 3. 三種「¥1 上限」做法

| 方案 | 做法 | 硬度 | 難度 | 建議 |
|------|------|------|------|------|
| **A. 餘額法** | 帳戶只充值 ¥1（或用一個專用帳號只充 ¥1） | ⭐⭐⭐ 最硬（餘額用完 → 官方回 **402 Insufficient Balance**） | ★ 最易 | ✅ **首選** |
| **B. Worker 每日上限** | 已內建 `DAILY_MAX = 40` | ⭐ 中等（Worker isolate 重啟會歸零，best-effort） | ★ 已做好 | ✅ 搭配 A |
| **C. KV 持久計數** | Worker 加 KV binding，記每日／每月累計 | ⭐⭐⭐ 硬（跨 isolate 持久） | ★★ 要多設 KV | 想要真正硬上限才做 |

**我的建議：A + B 雙保險**
- A 保證你**最壞情況只會蝕 ¥1**（因為餘額見底就 402，請求直接失敗）。
- B 防止有人**一日內**把 ¥1 刷光（40 次 ≈ ¥0.24–0.48）。

⚠️ **需要你自行核實**：DeepSeek 充值頁的**最低充值金額**我無法在文件查到（要登入平台才見到）。如果最低係 ¥10／¥50，就唔可以用「只充 ¥1」；改用「專用帳號 + Worker 上限」或者做方案 C。

## 4. 逐步設定（照做）

### 第 1 步：DeepSeek 建金鑰
1. <https://platform.deepseek.com/> → 登入 → **充值**（建議先充 ¥10 或最低金額；想嚴格控 ¥1 就充 ¥1，見 §3）
2. 左邊 **API keys** → **建立 API key** → 命名 `ziwei-web`
3. **立即複製**（只顯示一次）。貼喺自己本機記事本，**唔好貼去聊天／GitHub／截圖**

### 第 2 步：Cloudflare 建 Worker
1. <https://dash.cloudflare.com/> → **Workers & Pages** → **Create** → **Worker** → 命名 `ziwei-proxy`
2. **Edit code** → 全選刪除 → 貼上 `02-改進版\worker\ziwei-proxy-worker.js` 全文
3. 改 `ALLOWED_ORIGINS`：
   ```js
   const ALLOWED_ORIGINS = [
     "https://你的名.github.io",      // ← 你最終的 Pages 網域（只寫網域）
     "http://localhost:8080",         // 本機測試留著
     "http://127.0.0.1:8080"
   ];
   ```
4. **Deploy** → 記下網址：`https://ziwei-proxy.xxxx.workers.dev`

### 第 3 步：把金鑰放進 Worker（唯一一次接觸金鑰的地方）
Worker → **Settings** → **Variables and Secrets** → **Add**
- Type: **Secret**
- Name: `DEEPSEEK_API_KEY`
- Value: `sk-...`
→ **Save and Deploy**

> 之後金鑰只存在 Cloudflare 的加密 secret；前端、HTML、GitHub 都**冇**金鑰。

### 第 4 步：驗證 Worker（重要）
瀏覽器開任何一頁 → F12 → Console → 貼：

```js
fetch("https://ziwei-proxy.xxxx.workers.dev/chat", {
  method: "POST",
  headers: { "content-type": "application/json" },
  body: JSON.stringify({
    model: "deepseek-flash",
    messages: [{ role: "user", content: "只回覆兩個字：測試" }],
    max_tokens: 20,
    thinking: { type: "disabled" },
    stream: false
  })
}).then(r => r.text()).then(t => console.log("HTTP_OK", t.slice(0, 300)))
```

| 回應 | 意思 |
|------|------|
| 見到 `"content":"測試"` | ✅ 成功 |
| `origin not allowed` | ALLOWED_ORIGINS 未加你開呢頁嘅網域（本機用 localhost:8080 要經 `Serve-Local.cmd`） |
| `worker 未設定 DEEPSEEK_API_KEY` | Secret 名打錯或未 Deploy |
| `401` | 你嘅 key 錯／已撤銷 |
| `402` | **餘額用完**（就係「¥1 用完」嘅訊號） |

### 第 5 步：產生公開版 HTML
雙擊 `01-指令\Build-Public-Proxy.cmd` → 貼 Worker 網址 → 產出
`02-改進版\public\ziwei-ai-v2-public-<時間>.html`（**冇金鑰**）

### 第 6 步：本機先試（重要，唔好直接上 Pages）
1. 雙擊 `01-指令\Serve-Local.cmd` → 開著 `http://localhost:8080/`
2. 瀏覽器開 **`http://localhost:8080/public/ziwei-ai-v2-public-<時間>.html`**
   （用 `public` 那個檔，先確認 proxy 模式行得通）
3. 揀三張牌 → 開始解讀 → 應該**逐字出現**
4. 如果見到「origin not allowed」→ Worker 的 `ALLOWED_ORIGINS` 要包含 `http://localhost:8080`

> 用 `file://` 直接雙擊**唔得**（瀏覽器會送 `origin: null`，Worker 會擋），所以一定要用 `Serve-Local.cmd`。

### 第 7 步：上 GitHub Pages
1. 新 repo（例如 `ziwei-v2`）→ 把 public 檔改名 `index.html` → push
2. Settings → Pages → Source: `main` / `root` → Save
3. 等 1–2 分鐘 → 開 `https://你的名.github.io/ziwei-v2/`
4. **回頭**把呢個網域加入 Worker `ALLOWED_ORIGINS` → 重新 Deploy

## 6. 疑難排解

| 症狀 | 原因 | 解法 |
|------|------|------|
| `400 model not found` | 用咗舊名 `deepseek-chat` | 改成 `deepseek-flash` |
| 前端停很久才出字 | thinking 未關 | v2 已預設 `thinking: disabled`；確認 payload 有帶 |
| CORS 錯誤 | Worker 未回應 OPTIONS 或 origin 未准 | 重新 Deploy 最新 worker.js；加 origin |
| 一直 429 | 超過每 IP 8 次／分 或 每日 40 次 | 調 `RATE_MAX` / `DAILY_MAX` |
| 402 | 餘額用完（¥1 用完） | 充值，或當作「上限生效」 |
