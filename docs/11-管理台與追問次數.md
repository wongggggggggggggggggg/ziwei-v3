## 一、追問次數

解讀下面「追問」標題旁會顯示一個紫色膠囊數字，例如：**追問 3 次**

| 行為 | 數字變化 |
|---|---|
| 開始新解讀 | 歸零 |
| 每次追問成功 | +1 |
| 由歷史載入 | 顯示該筆當時的追問數 |

實作位置：`updateFollowupCount()`（v3.3.0 新增），元素 `#followupCount`。

## 三、登入

| 欄位 | 值 |
|---|---|
| 帳號 | `kevin` |
| 密碼 | **由 Worker 驗證**，即環境變數 `ADMIN_PASSWORD`（未設定時退回 `UNLOCK_PASSWORD` = `tccs`） |

### ⚠️ 想用密碼 `s1601032` → 你要在 Cloudflare 加一個變數（唔需要貼代碼）

1. Cloudflare → **Workers & Pages** → `ziwe-kevin` → **設定 / Settings**
2. **變數與密鑰 / Variables and Secrets** → **新增 / Add**
3. 類型 **Secret**（或 Text），名稱：`ADMIN_PASSWORD`，值：`s1601032`
4. **保存並部署 / Save and deploy**

設定後：`kevin` + `s1601032` 可登入；`tccs` 就只留給解鎖碼用。

## 四、管理台可以睇什麼

| 區塊 | 內容 |
|---|---|
| KPI 卡 | 驗證訪客數、事件數、統計週、最後載入時間 |
| 訪客 | 名字 / IP / 驗證時間（最近 50 位） |
| 事件 | 時間 / 名字 / 類型（解讀或追問）/ 牌組 / 隨機或自選 / **追問問題原文**（最近 80 條） |
| 原始 JSON | 整個 API 回應，方便複製 |
| 工具 | 搜尋（名字／IP／牌名／問題）、重新載入、匯出 JSON、登出 |

## 五、安全說明（誠實）

| 項目 | 實情 |
|---|---|
| 帳號 `kevin` | 寫在頁面原始碼內，**唔係秘密**（任何人睇原始碼都知）。真正把关係密碼 |
| 密碼 | 由 Worker 用常數時間比對；錯就回 401。**密碼冇寫在頁面內**（已驗證 admin.html 內不含 `s1601032`） |
| 密碼傳輸 | 用 query string（`?key=...`）→ 會出現在瀏覽器網絡紀錄與 Cloudflare 日誌。屬可接受但不理想 |
| 更安全做法 | 買網域 + Cloudflare Access（登入頁由 Cloudflare 提供，密碼不會出現在 URL） |
| 資料 | IP 完整存於 KV（只有你睇）；API 回傳給主站時會遮罩 |
