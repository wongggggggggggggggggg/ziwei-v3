## 1. 修好嘅問題（原版真 bug / 風險）

| # | 問題（原版） | 嚴重度 | v2 點修 |
|---|--------------|--------|---------|
| 1 | `const DEEPSEEK_API_KEY = ""` 硬編碼位留在 public repo：任何人手改就等於把金鑰 commit 上網 | 🔴 高 | 完全移除，改成 `CONFIG` 三模式；私人版用腳本本地注入 |
| 2 | 金鑰明文存 localStorage（`zwds.apiKey`） | 🔴 高 | 預設只存 sessionStorage；要「記住」才寫 localStorage；顯示時遮罩 |
| 3 | **冇檢查 `finish_reason`**：`max_tokens: 2400` 爆額時，第七段「行動建議」被靜靜斬走，使用者完全唔知 | 🟡 中 | 讀 `finish_reason === "length"` → 顯示黃色警示條；`max_tokens` 2400 → 3200 |
| 4 | 429 / 5xx 完全冇重試，要使用者手動撳 | 🟡 中 | 自動重試最多 3 次（1.2s / 2.6s backoff），只針對 429/500/502/503/504 + 逾時 + 網絡錯 |
| 5 | 標籤寫「主星牌組 14 + 24」，實際陣列有 25 張（24 雙星 + 空宮） | 🟢 低 | 改成 `14 + 25`；hero-meta 改成「24 雙星 + 空宮」 |
| 6 | 冇 CSP，任何注入都能把金鑰送去任意外域 | 🟡 中 | 加 `Content-Security-Policy`，`connect-src` 只准 DeepSeek + `*.workers.dev` |
| 7 | 模型名 `deepseek-chat` 已於 2026-07-24 停用（官方公告） | 🔴 高 | 改 `deepseek-flash`，UI 亦顯示實際模型名 |
| 8 | 冇指定 thinking → 預設開啟（temperature 失效、變慢、變貴） | 🟡 中 | 明確 `thinking: {type:"disabled"}` |

## 2. 新增功能（原版冇）

| 功能 | 說明 | 程式位置 |
|------|------|----------|
| **串流輸出** | `stream: true` + `ReadableStream` + SSE 解析，逐字出現 | `readStream()` / `parseSSELine()` |
| **解讀紀錄** | 最多 20 筆（localStorage `zwds.history`），可「載入／複製／刪除」單筆 | `loadHistory()` / `renderHistory()` |
| **下載 .md** | 把解讀存成 Markdown 檔（帶版本與時間註解） | `downloadReading()` |
| **連線模式顯示** | 設定頁顯示「代理／內嵌／自備」，並只顯示遮罩金鑰 | `syncSettingsUI()` |
| **記住金鑰開關** | 勾＝localStorage；不勾＝sessionStorage | `saveSettings()` |
| **代理模式** | 前端完全唔接觸金鑰（`worker.js` 代發） | `buildReadingRequest()` |
| **公開示警** | 內嵌金鑰 + 非本機 → 頂部紅色警示條 | `warnIfInlineKeyExposed()` |
| **天馬** | 輔星 21 → 22（補上常見缺項） | `SUPPORT_CARDS` |
| **自測接口** | `window.__zwdsInternals` 暴露純函式，供 `selftest.mjs` 驗證 | 模組尾部 |

## 3. 保持不變（刻意唔改）

- 原版 46,960 字元 CSS **一個字都冇改**（只追加新樣式），所以外觀、動效、深淺色主題應該同原版一致。
- 七段 prompt 結構、書寫原則、免責聲明、AI 語氣指令：原文保留。
- 牌組名稱、24 個雙星配對、十二長生順序：完全一致（只加天馬）。
- 單檔、零依賴、可離線開（除 AI 解讀）：保持一致。

## 4. 已知未做（YAGNI / 風險控制）

| 項目 | 為什麼唔做 |
|------|-----------|
| 拆成多檔（ES module + build） | 會失去「傳一個檔就用到」的優點；你想公開分享，單檔更實際 |
| 分享成圖（canvas 截圖） | 需要字型嵌入／排版處理，體積大增，未經驗證唔敢加 |
| 四化牌組獨立成組 | 會改動牌卡資料模型（影響 localStorage 既有選擇），留給你自己決定 |
| 列印樣式 | 低價值，且我無法視覺驗證 |
