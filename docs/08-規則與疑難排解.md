## 一、目前生效的規則（Rule）

| # | 規則 | 數值 | 存在哪裡 | 為什麼 |
|---|---|---|---|---|
| R1 | 每個 IP 每週免費次數 | **10 次** | Worker `WEEKLY_MAX` | 控制成本，一班朋友夠用 |
| R2 | 輸入解鎖碼的加送（個人） | **+10 次／次** | Worker `UNLOCK_BONUS` | 你私下給朋友解鎖 |
| R3 | **全站每週總次數（所有 IP 合計）** | **40 次** | Worker `GLOBAL_WEEKLY_MAX` | **¥1 預算的硬剎車**：到頂即全站停 |
| R4 | 解鎖碼的加送（全站） | **+40 次／次** | Worker `GLOBAL_UNLOCK_BONUS` | 解鎖一次＝放行多一輪 |
| R5 | 每 IP 每分鐘請求上限 | 6 次 | Worker `RATE_MAX` | 擋瞬時刷 |
| R6 | 解鎖碼嘗試次數 | 5 次 / 10 分鐘 | Worker 內寫死 | 擋暴力猜密碼 |
| R7 | 解鎖需通過 Turnstile | 開／關看有無 `TURNSTILE_SECRET` | Worker | 擋自動化腳本 |
| R8 | 週界線 | 格林威治時間星期一 00:00 ＝ **香港時間星期一 08:00** | Worker `weekKey()` | 每週重置 |
| R9 | 配額持久化 | 有 `ZWDS_KV` 就持久；冇就記憶體（重啟歸零） | Worker | 防止「無限次」 |
| R10 | 錯誤碼 | `quota_exhausted`（個人用完）／`global_blocked`（全站用完）／`rate`（太快）／`turnstile`（驗證失敗） | Worker | 前端可以分開處理 |

### 前端怎樣顯示
- **頂欄右邊**有一個膠囊按鈕：`本週 8 次` → 點它會打開設定並顯示詳情
  - 剩 ≤ 2 次 → **橙色**
  - 全站已滿 → **紅色「全站已滿」**
- 設定頁「本週使用次數」顯示：
  `你的 IP：1.2.3.*｜個人：已用 2 / 10（剩 8）｜全站：已用 5 / 40（剩 35）`

## 一之二、整站人機驗證（v2.5，規則 R11–R13）

| # | 規則 | 說明 |
|---|---|---|
| R11 | 開頁即驗證 | 代理版一打開就出 Cloudflare 驗證遮罩；**未通過不可使用**（「開始解讀」會被擋） |
| R12 | 通過後發 session | Worker `POST /verify` 驗 Turnstile → 簽發 **HMAC session token**（30 分鐘） |
| R13 | 每次 /chat 都要 session | 冇 session 或過期 → `401 session_required`，前端自動**重新彈出驗證窗** |

> ⚠️ 若 Worker 仍是舊版（冇 `/verify`），前端會**自動放行**（避免整站卡死），但就等於冇保護 → 所以一定要貼最新 Worker。

## 二、怎樣「解鎖」（三種方法）

### 方法 A：在網頁輸入解鎖碼（你朋友用）
1. 打開網站 → 右上 **齒輪**（或點頂欄的次數膠囊）
2. 「本週使用次數」→ 輸入 `tccs`
3. 完成 Turnstile → 按 **→**
4. 結果：個人 **+10**，全站 **+40**（即時解除全站封鎖）

### 方法 B：在 Cloudflare 直接改（你自己用，唔需要解密碼）
1. Cloudflare → **存儲和數據庫 → KV → `zwds-quota`**
2. 找 key：
   - 個人：`q:2026-11-09:<IP>`（值是 `{"used":10,"bonus":0}`）
   - 全站：`g:2026-11-09`（值是 `{"used":40,"bonus":0}`）
3. 編輯：把 `used` 改細（例如 0），或把 `bonus` 加大（例如 40）
4. 保存 → 立即生效（唔需要重新部署）

> 💡 快速全站解封：把 `g:<本週星期一日期>` 的 `used` 改成 `0`。

### 方法 C：改規則（長期）
Worker 頂部改 `GLOBAL_WEEKLY_MAX`（例如 80）→ **部署**。

## 三、問題 → 解決（Problem → Solution）

### 3.1 使用者會見到的錯誤

| 你會見到 | 錯誤碼 | 意思 | 解決 |
|---|---|---|---|
| 「本週免費次數已用完（10 次）」 | `quota_exhausted` | **你這個 IP** 的 10 次用完 | 輸入解鎖碼 +10；或等星期一 08:00 |
| 「本週全站次數已用完（40 次）」 | `global_blocked` | **全站** 40 次用完（所有人合計） | 輸入解鎖碼（+40 全站）；或你在 KV 把 `g:` 的 used 改 0 |
| 「請求太頻繁，請一分鐘後再試」 | `rate` | 同一 IP 一分鐘超過 6 次 | 等一分鐘 |
| 「解鎖碼不正確」 | `bad_password` | 打錯字／有空格 | 重新輸入 `tccs` |
| 「嘗試次數過多，請 10 分鐘後再試」 | `unlock_rate` | 10 分鐘內錯 5 次 | 等 10 分鐘 |
| 「人機驗證失敗（invalid-input-response）」 | `turnstile` | Turnstile token 過期／假 | 重新整理頁面再試 |
| 「人機驗證失敗（invalid-input-secret）」 | `turnstile` | **Worker 的 `TURNSTILE_SECRET` 錯** | 重貼 Secret Key（唔係 Site Key） |
| 「人機驗證失敗（missing-input-response）」 | `turnstile` | 前端冇送到 token | 確認 Worker 是 v3.1+、前端是 v2.3+ |
| 「origin not allowed」 | `origin` | 網域不在白名單 | Worker `ALLOWED_ORIGINS` 要包含 `https://wongggggggggggggggggg.github.io` |
| 「model not allowed」 | `model` | 傳了不在白名單的模型 | 用 `deepseek-flash` 或 `deepseek-v4-pro` |
| 「API 金鑰無效」 | 401 | `DEEPSEEK_API_KEY` 錯／已撤銷 | 重設 Secret |
| 「餘額不足」 | 402 | DeepSeek 帳戶冇錢（¥1 用完） | 充值 |
| 「Worker 未設定 DEEPSEEK_API_KEY」 | `no_key` | Secret 名打錯／未部署 | 名一定要 `DEEPSEEK_API_KEY` |

### 3.2 設定／部署類

| 症狀 | 原因 | 解決 |
|---|---|---|
| 設定頁顯示「讀取失敗」 | Worker 還是舊版（冇 `/quota`） | 貼最新 Worker 並部署 |
| 「本週次數」每次都變回 10 | **冇綁 KV** | 加綁定 `ZWDS_KV` → `zwds-quota` |
| 改完前端見不到新版 | GitHub Pages 快取 `max-age=600`（10 分鐘） | `Ctrl+F5` 或網址加 `?cb=123` |
| Turnstile 框不出現 | Widget 的 Hostname 未含你的網域 | Turnstile → Widget → 加 `wongggggggggggggggggg.github.io` |
| Turnstile 一直轉圈 | 你的網絡擋了 `challenges.cloudflare.com` | 換網絡／關 VPN |
| 解鎖後仍然被擋 | 你解鎖的是「個人」，全站已滿要**再解鎖一次**（或你在 KV 改 `g:`） | 見 §2 |
| 全站 40 次很快用完 | 有爬蟲／朋友狂刷 | 降低 `GLOBAL_WEEKLY_MAX`、加 Turnstile（已加）、或設 Cloudflare WAF |

### 3.3 我踩過的坑（已記錄在 MISTAKES.md）

| # | 坑 | 教訓 |
|---|---|---|
| #029 | fine-grained GitHub PAT 未授權 repo → 全 403 | fine-grained 只能勾「已存在」的 repo；classic `repo` 一次搞定 |
| #030 | Worker 新版只寫新檔名，canonical 檔仍是舊版 | 改版要覆寫 canonical 並 grep 驗證所有副本 |

## 四、健康檢查（3 條，30 秒）

在網站頁面按 **F12 → Console** 貼：

```js
// ① 睇配額（個人 + 全站 + IP）
fetch("https://ziwe-kevin.www-wongkevin404.workers.dev/quota")
  .then(r=>r.json()).then(console.log)

// ② 睇 Turnstile Secret 對唔對（假 token 應回 invalid-input-response）
fetch("https://ziwe-kevin.www-wongkevin404.workers.dev/unlock", {
  method:"POST", headers:{"content-type":"application/json"},
  body: JSON.stringify({ password:"tccs", "cf-turnstile-response":"dummy" })
}).then(r=>r.json()).then(console.log)

// ③ 真解讀一次（會扣 1 次）
fetch("https://ziwe-kevin.www-wongkevin404.workers.dev/chat", {
  method:"POST", headers:{"content-type":"application/json"},
  body: JSON.stringify({ model:"deepseek-flash", max_tokens:8, thinking:{type:"disabled"},
    messages:[{role:"user",content:"回覆兩字：測試"}] })
}).then(r=>console.log(r.status, r.headers.get("x-quota-remaining"), r.headers.get("x-global-remaining")))
```

期望：① 有 `ip / used / limit / globalUsed / globalLimit`；② `invalid-input-response`；③ `200 9 39`（示例）
