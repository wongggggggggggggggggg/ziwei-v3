## 一、匯出（下載 .md）— 真的可用

按結果區的 **「下載 .md」**，會得到一個檔案，內容分兩部分：

    <!-- ZWDS-META {"name":"Kevin","at":1763...,"mode":"random","markdown":"...","followups":[...] } -->

    # 紫微斗數 AI 解牌 · 解讀紀錄
    - 名字：Kevin
    - 日期：2026-11-15 22:40
    - 主星：紫微／輔星：左輔／長生：長生
    - 抽牌方式：隨機抽牌
    - 版本：v3.2.0

    ---
    （七段解讀）
    ---
    ## 追問
    ### 問 1：那我今年適合轉工嗎？
    （答案）

- **上半**：人看得懂的 Markdown
- **第一行 ZWDS-META**：機器讀的 JSON → 令檔案可以**原封不動匯入回來**
- 若瀏覽器不支援 createObjectURL，會自動改用 data: URL（雙重保險）

## 二、匯入（把之前下載的檔案載回頁面）

按 **「匯入 .md」** → 選檔案：

| 情況 | 結果 |
|---|---|
| 有 ZWDS-META | 完整還原：名字、日期、牌組、抽牌方式、解讀、**所有追問** |
| 只有普通 Markdown | 直接把內容顯示在結果區（牌組需自己重選） |

好處：換電腦／換瀏覽器／清 cache 之後，舊紀錄仍然可以拿回來。

---

## 三、列印 / 存 PDF

按 **「列印 / 存 PDF」** → 瀏覽器列印視窗 → 選「**另存為 PDF**」。

為什麼用瀏覽器列印而不是產生 PDF 檔？

- 零依賴、零額外函式庫（保持單檔）
- 中文字型由瀏覽器處理，不會出現亂碼
- 排版用 @media print 控制：只印「名字／日期／牌組／解讀／追問／免責聲明」，UI 全部隱藏

---

## 四、解讀歷史（變漂亮了）

齒輪旁「歷史」→ 對話框：

- **搜尋框**：可搜名字、牌名、追問內容（即時過濾）
- **每筆一張卡**：名字 · 日期 / 主星／輔星／長生 · 隨機或自選 · 追問 N 條 / 摘要
- **四個按鈕**：載入（連追問一併還原）／複製／**下載（單筆 .md）**／刪除（只刪該筆）

## 五、使用紀錄（記錄名字、問什麼、揀了什麼牌）

前端每次完成動作會送 POST /event（**不扣額度**）：

| 事件 | 內容 |
|---|---|
| reading | 名字、主星、輔星、長生、**random 或 click** |
| followup | 名字、問題原文（最多 300 字）、當時牌組 |

Worker 寫入 KV：ev:<本週星期一>（最多 500 筆，保留 30 日）。
