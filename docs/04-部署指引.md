# 04 · 部署指引（Worker 代理 + GitHub Pages）

> 目標：公開一個**完全冇金鑰**的網頁，但訪客可以用**你的** DeepSeek 額度。
> 你需要：一個 Cloudflare 帳號（免費）、一個 GitHub 帳號。

---

## 第一步：部署 Worker（5 分鐘）

1. 登入 <https://dash.cloudflare.com/> → 左邊 **Workers & Pages** → **Create** → **Worker**。
2. 名稱隨意，例如 `ziwei-proxy`。建立後按 **Edit code**。
3. **整段刪除**預設示範碼，貼上 `02-改進版\worker\ziwei-proxy-worker.js` 全文。
4. 改兩處：
   - `ALLOWED_ORIGINS`：`"https://YOUR-NAME.github.io"` → 你真正的 Pages 網域（**只寫網域，唔好寫路徑**）。
     本機測試可以留 `http://localhost:8080`。
   - `RATE_MAX`：預設每 IP 每分鐘 8 次，可自行調整。
5. **設定金鑰（關鍵）**：Worker → **Settings** → **Variables and Secrets** → **Add**：
   - Type: **Secret**
   - Name: `DEEPSEEK_API_KEY`
   - Value: 你的 `sk-...`
6. **Deploy**，記下網址，形如 `https://ziwei-proxy.你的子域.workers.dev`。

### 驗證 Worker（用 PowerShell 實測）

```powershell
$body = '{"model":"deepseek-chat","messages":[{"role":"user","content":"say hi"}],"max_tokens":10,"stream":false}'
Invoke-RestMethod -Method Post -Uri "https://ziwei-proxy.你的子域.workers.dev/chat" `
  -ContentType "application/json" -Body $body -Headers @{ Origin = "https://YOUR-NAME.github.io" }
```

- 回 200 + 內容 → Worker 正常。
- 回 403 `origin not allowed` → `ALLOWED_ORIGINS` 未加你的網域。
- 回 500 `worker 未設定 DEEPSEEK_API_KEY` → secret 未設好。

> ⚠️ 本機 shell 有已知 HTTPS 問題（`schannel: SEC_E_NO_CREDENTIALS`），如果 `Invoke-RestMethod` 失敗，改用瀏覽器 F12 → Console：
> ```js
> fetch("https://ziwei-proxy.xxx.workers.dev/chat", {method:"POST", headers:{"content-type":"application/json"}, body: JSON.stringify({model:"deepseek-chat", messages:[{role:"user",content:"hi"}], max_tokens:10, stream:false})}).then(r=>r.text()).then(console.log)
> ```

## 第二步：產生公開版 HTML

雙擊 `01-指令\Build-Public-Proxy.cmd` → 貼上 Worker 網址 → 產出
`02-改進版\public\ziwei-ai-v2-public-<時間>.html`

呢個檔案：
- `PROXY_URL` 已填好
- **冇任何 API 金鑰**
- 若果你用自訂網域（唔係 `*.workers.dev`），腳本會自動把該網域加入 CSP `connect-src`

---

## 第三步：上 GitHub Pages

1. 建立新 repo（例如 `ziwei-v2`）。
2. 把 public 檔改名做 `index.html`（咁根路徑就開得到 —— 原版就係因為冇 index.html，根路徑 404）。
3. Push，然後 Settings → Pages → Source: `Deploy from a branch` → `main` / `(root)`。
4. 等 1–2 分鐘，開 `https://你的名.github.io/ziwei-v2/`。

> **記得回頭更新 Worker 的 `ALLOWED_ORIGINS`**，加入最終網域，否則會 403。

## 第四步：考慮加保護（可選）

| 保護 | 做法 | 效果 |
|------|------|------|
| 限流 | 已內建（每 IP 每分鐘 8 次） | 阻 casual 刷額度 |
| 每日總量上限 | Worker 加 Durable Object／KV 計數 | 防大規模盜用 |
| Cloudflare Turnstile | 前端加人機驗證，Worker 驗 token | 擋 bot |
| 只准自己人 | 加簡單密碼／邀請碼 header | 需要你分發 |

唔做都已經比原版安全**多過一個數量級**（原版根本冇「前後端」之分）。

## 成本

- Cloudflare Workers 免費方案：每日 100,000 次請求、每次上限 10ms CPU（本用途綽綽有餘）。
- DeepSeek token 費用：由你的帳戶支付。一次解讀約 3,000–5,000 tokens（視輸出長度）。

## 疑難排解

| 症狀 | 原因 | 解法 |
|------|------|------|
| `origin not allowed` | ALLOWED_ORIGINS 未含你的網域 | 加入並重新 Deploy |
| 前端報 CORS | Worker 未回應 OPTIONS | 確認用最新 `worker.js` |
| 串流中斷／唔逐字 | 中間有代理緩衝 | Cloudflare 正常支援串流；檢查有無其他 CDN |
| `file://` 開唔到（origin null） | 瀏覽器 CORS | 用 `Serve-Local.cmd` 開 `http://localhost:8080` |
| 一直 429 | 你或訪客太頻繁 | 調高 `RATE_MAX` 或等一分鐘 |
