## v3 新增：追問

解讀完 → 下面出現「追問」輸入框 → 問你想問的 → 答案**逐字串流**出現。

**規則（寫在系統提示詞）**
1. 只答你問的那一條，**不重寫**原本七段解讀
2. **沿用原牌組（主星／輔星／長生）與原結論**，有矛盾會先指出
3. 長度按難度：簡單 1–3 句、中等 1–2 段、複雜可分點；**最多 3000 中文字**
4. **不答程式碼、演算法、數學計算、功課解題**（前端會先擋，AI 也會拒答）
5. 不做醫療／法律／投資具體決策，不恐嚇、不宿命論

**額度**：每次追問 = 1 次呼叫 → 扣 1 次（個人每週 10 次、全站 40 次；解鎖碼可加）

## 使用步驟
1. 開網站 → 輸入短名 → 完成 Cloudflare 驗證（30 分鐘有效）
2. 揀：主星 → 輔星 → 十二長生
3. 按「開始解讀」→ 逐字出現七段解讀
4. 下面「追問」輸入問題 → 送出
5. 可複製／下載 .md／在「歷史」找回（追問會一併保存）
